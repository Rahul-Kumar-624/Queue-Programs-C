# Queue Programming Questions in C

This repository contains C implementations for various Queue data structure operations.

## Included Programs:
1. **Linear Queue**: Array implementation doing enqueue, dequeue, and display.
2. **Circular Queue**: Fixed-size circular array queue operations.
3. **Double Ended Queue (Deque)**: Insertion/Deletion from both ends.
4. **Priority Queue**: Priority-based enqueue and dequeue.
